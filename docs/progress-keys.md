# 引き継ぎの記録の名前（ProgressKey）

チュートリアルのあいだで引き継ぐ「記録」の名前の一覧。しくみは [architecture.md「チュートリアルのあいだでデータを引き継ぐ（案）」](architecture.md#チュートリアルのあいだでデータを引き継ぐ案) にある。

- 記録を足す PR で、この表に 1 行足す。ここにない名前を、コードやデータに書かない。
- 名前は「事実」にする（例: `texture-mapping-learned`）。特定のチュートリアルを指す名前（`t2-done`）は避ける。
- 英小文字とハイフン。

| 名前 | 意味 | 残すステップ | 使うステップ |
|---|---|---|---|
| （まだない） | | | |
