# 名前の一覧（覚えたこと・場面）

チュートリアルまわりで使う名前の一覧。しくみは [architecture.md「チュートリアルのあいだでデータを引き継ぐ」](architecture.md#チュートリアルのあいだでデータを引き継ぐ) と [Tutorial/README.md](../Assets/Scripts/Tutorial/README.md) にある。

- 名前を足す PR で、この表に 1 行足す。ここにない名前を、コードに書かない。
- 英小文字とハイフン。

## 覚えたこと（`TutorialMemory` の名前）

チュートリアルのあいだで引き継ぐ。「事実」の名前にする（例: `texture-mapping-learned`）。特定のチュートリアルを指す名前（`t2-done`）は避ける。

| 名前 | 意味 | 覚えるチュートリアル | 使うチュートリアル |
|---|---|---|---|
| （まだない） | | | |

## 場面（`PhaseId` の名前）

`Phases.Current` になる。チュートリアルの人形劇スクリプトの `Phase` で決める。番号ではなく、やることを表す名前にする（順番が変わっても、読む側を直さずに済む）。フィールドや UI は、これを読んで動きを分けてよい。

| 名前 | 意味 | 決める所 |
|---|---|---|
| （まだない） | 例: `fork`（フォークの使い方）、`spawn`（物が生まれる）、`recognize`（食感で変わる・欲しい物）、`deliver`（届ける）、`main`（本編）、`ending` | |
