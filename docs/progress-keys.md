# 名前の一覧（覚えたこと・場面）

チュートリアルまわりで使う名前の一覧。しくみは [architecture.md「チュートリアルのあいだでデータを引き継ぐ」](architecture.md#チュートリアルのあいだでデータを引き継ぐ) と [Tutorial/README.md](../Assets/Scripts/Tutorial/README.md) にある。

- 名前を足す PR で、この表に 1 行足す。ここにない名前を、コードに書かない。
- 英小文字とハイフン。

## 覚えたこと（`TutorialMemory` の名前）

チュートリアルのあいだで引き継ぐ。「事実」の名前にする（例: `texture-mapping-learned`）。特定のチュートリアルを指す名前（`t2-done`）は避ける。

| 名前 | 意味 | 覚えるチュートリアル | 使うチュートリアル |
|---|---|---|---|
| `fork-learned` | 雲を刺し、口に含み、ボタンで決定するまでを一度やった | チュートリアル 1 | チュートリアル 2（説明を短くする） |
| `food-born` | 口から物が生まれることを見た | チュートリアル 2 | チュートリアル 3 |
| `texture-shadow-seen` | 影を見ながら、食感と生まれる物の対応を見た | チュートリアル 2 | チュートリアル 3（影を薄くする） |
| `request-seen` | 村人の欲しい物の吹き出しを見た | チュートリアル 3 | チュートリアル 4 |
| `delivered-by-standing` | 立つ場所で届け先が決まることを知り、正しく届けた | チュートリアル 4 | 本編 |

## 場面（`PhaseId` の名前）

`Phases.Current` になる。チュートリアルの人形劇スクリプトの `Phase` で決める。番号ではなく、やることを表す名前にする（順番が変わっても、読む側を直さずに済む）。フィールドや UI は、これを読んで動きを分けてよい。

| 名前 | 意味 | 決める所 |
|---|---|---|
| `prologue` | 導入の動画（プロローグ。シナリオブック S1） | `PrologueVideo` |
| `fork` | フォークの使い方（チュートリアル 1。シナリオブック S3） | `T1Fork` |
| `spawn` | 口から物が生まれる（チュートリアル 2。S4） | `T2Spawn` |
| `recognize` | 食感で物が変わる・欲しい物を知る（チュートリアル 3。S5） | `T3Recognize` |
| `deliver` | 立つ場所で届ける（チュートリアル 4。S6） | `T4Deliver` |
