# フィールドの Prefab を仕上げる手順

この手順は、海・山・草原・村の担当者向けです。上から順に進めると、自分のフィールドの Prefab が完成します。完成した Prefab は、チュートリアルでも本編でも使えます。各手順では、はじめに「もう済んでいるか」を確かめます。済んでいれば次へ進みます。済んでいなければ、書いてある作業をしてから次へ進みます。

## 前提

### 体験の流れ
体験者は、ミニチュアの村の周りを歩きます。体験者は、フィールドの前に立ちます。そこでデバイスを噛んで、口から食べ物を生みます。生まれた食べ物は、顔を向けた方へ飛びます。体験者は、欲しがっている村人を狙って飛ばします。欲しがっていた物が届くと、そのフィールドが少しずつ元の姿に戻ります。

### 自分が直すもの
直すのは、自分のフィールドの Prefab 1 つだけです。共有シーン（Main）は触りません。Prefab はほかの人と別のファイルなので、Scene Fusion を使わずに、自分のペースで作業できます。

| 担当 | フィールドの名前 | Prefab |
|---|---|---|
| 海 | `sea` | `Assets/Resources/Prefabs/Sea/Sea.prefab` |
| 山 | `mountain` | `Assets/Resources/Prefabs/Mount/MountVer2.prefab` |
| 草原 | `grassland` | `Assets/Resources/Prefabs/Grass/Grass.prefab` |
| 村 | `village` | `Assets/Resources/Prefabs/Village/Village.prefab` |

手順の中の `<名前>` は、この表の「フィールドの名前」に読み替えてください。

### 見本
村の Prefab（`Assets/Resources/Prefabs/Village/Village.prefab`）が見本です。迷ったら、村の Prefab を開いて見比べてください。村の Prefab は 1〜7 章が済んでいるので、村の担当は 8 章と 9 章だけを行います。

### 使う部品
どの部品も、Inspector の **Add Component** で名前を入れると付けられます。

| 部品 | 何をするか |
|---|---|
| `FieldStages` | このフィールドの名前を持ちます。欲しい物を順に出し、届いた物を受け取ります |
| `FieldStep` | 欲しい物 1 つ分です。その物が届くと、子に置いた物が現れます |
| `FoodTable` | このフィールドで、どの食感からどの食べ物が生まれるかの表です |
| `DeliveryZone` | 食べ物がこの範囲に落ちたら、このフィールドに届いたことにします |
| `StandArea` | 体験者がこの床の上に立つと、このフィールドの前にいることにします。チュートリアルが「ここに立って」と案内するときに使います |
| `DeliveryFx` | 物が届いたときの反応です。欲しい物なら村人が喜び、違う物なら村人ががっかりします。`FieldStages` があれば自動で付くので、自分で付ける必要はありません |
| `CueReaction` | チュートリアルからの合図を受けて、物を出したり消したりします。合図は `sea.glow` のような名前の知らせです。海の担当だけが使います |

### できあがりの形
Hierarchy で、次の形になれば完成です。`< >` の所は、フィールドごとに中身が違います。

```
<フィールド>   ← FieldStages / FoodTable / Box Collider / DeliveryZone（海だけ CueReaction も）
├─ Steps
│   ├─ 1 <欲しい物>        ← FieldStep
│   │   └─ <届くと現れる物>
│   └─ …
├─ <最初からある物>
├─ <村人>
├─ <ステップが済むと消える物>
├─ StandArea              ← StandArea
│   └─ Footprint
└─ Glow                   ← 海だけ。海が光って見える物
```

### 始める前にそろえておくもの
- PR #313 が main に入っていること。`StandArea` と `CueReaction` は、この PR で入ります。
- 欲しい物の食べ物の Prefab が、`Assets/Resources/Prefabs/Food/` にあること。無い食べ物は、自分で先に作ります。作れなければ、Food の担当に頼みます。

分からない所があれば、#313 か Slack のスレッドで聞いてください。

## 1. 準備
1. PR #313 がマージされているかを確かめます。
   - マージ済み: 手順 2 へ進みます。
   - まだ: PR #313 がマージされるまで待ちます。その後、手順 2 へ進みます。
2. main を pull します。
3. 自分の作業ブランチを作ります。
4. Project ウィンドウで、自分の Prefab をダブルクリックして開きます。

## 2. フィールドの名前を付ける
1. Hierarchy で、一番上のオブジェクトを選びます。
2. Inspector に `FieldStages` が付いているかを確かめます。
   - 付いている: 手順 3 へ進みます。
   - 付いていない: `FieldStages` を付けます。付けたら、手順 3 へ進みます。
3. `FieldStages` の **Field Id** が `<名前>` になっているかを確かめます。
   - なっている: 次の章へ進みます。
   - なっていない: **Field Id** に `<名前>` と入れます。入れたら、次の章へ進みます。

## 3. 欲しい物を並べる
1. 一番上のオブジェクトの子に、`Steps` があるかを確かめます。
   - ある: 手順 2 へ進みます。
   - ない: 一番上のオブジェクトを右クリックし、**Create Empty** を選びます。名前を `Steps` にします。作ったら、手順 2 へ進みます。
2. 欲しい物を全部作るまで、次の a〜e をくり返します。a〜e で、欲しい物 1 つ分を作ります。

   体験中、村人は上に置いたステップの物から順に欲しがります。
   - a. `Steps` を右クリックし、**Create Empty** を選びます。名前は `<番号> <食べ物>` にします（例: `1 fish`）。
   - b. `FieldStep` を付けます。
   - c. **Food** に、食べ物の ID を入れます。ID は、`Assets/Resources/Prefabs/Food/` にある Prefab の名前と同じです（例: `fish`）。
   - d. その物が届いたときに現れてほしい物を、このオブジェクトの子にドラッグします。
   - e. その物が届いたときに消えてほしい物（枯れた木など）を、**Hide When Done** にドラッグします。
3. チュートリアル 3 と 4 では、海が魚を欲しがります。そのため、海の担当だけ、**Food** が `fish` のステップがあるかを確かめます。
   - ある: 手順 4 へ進みます。
   - ない: 手順 2 の a〜e で、`fish` のステップを作ります。作ったら、手順 4 へ進みます。
4. 各ステップの **Helped** に、そのステップで助かる村人が入っているかを確かめます。ここに入れた村人の頭の上に、欲しい物の吹き出しが出ます。
   - 入っている: 次の章へ進みます。
   - 入っていない: 村人をドラッグして入れます。入れたら、次の章へ進みます。
   - 村人がまだいない: 空のままで、次の章へ進みます。この場合、吹き出しは村人の頭の上ではなく、ステップの位置に出ます。

## 4. 食べ物の表を付ける
1. 一番上のオブジェクトに、`FoodTable` が付いているかを確かめます。
   - 付いている: 手順 2 へ進みます。
   - 付いていない: `FoodTable` を付けます。付けたら、手順 2 へ進みます。
2. `FoodTable` の **Field Id** が `<名前>` になっているかを確かめます。
   - なっている: 手順 3 へ進みます。
   - なっていない: `<名前>` と入れます。入れたら、手順 3 へ進みます。
3. **Rows** に、このフィールドの食べ物が全部入っているかを確かめます。
   - 入っている: 次の章へ進みます。
   - 入っていない: 食べ物 1 つにつき、1 行足します。全部入れたら、次の章へ進みます。

1 行に入れるものは、次の 2 つです。
- **Texture**: 食感の名前を入れます。名前はまだ決まっていません。決まるまでは、仮の名前 `placeholder-a`・`placeholder-b`・`placeholder-c`・`placeholder-d` のどれかを入れます。名前を決めるのは #54 です。

`placeholder-e` と `placeholder-f` は入れません。この 2 つは、どこでもリンゴと魚が生まれるように、チュートリアル用に取ってあります。そのため、1 つのフィールドで生める食べ物は 4 つまでです。
- **Food**: その食感から生まれる食べ物の Prefab です。

## 5. 食べ物が届く範囲を作る
1. 一番上のオブジェクトに、**Is Trigger** が入った `Box Collider` が付いているかを確かめます。
   - 付いている: 手順 2 へ進みます。
   - 付いていない: `Box Collider` を付けます。**Is Trigger** を入れたら、手順 2 へ進みます。

台の地面用に付いている `Box Collider` は、消さずに残します。食べ物が届く範囲を決めるため、`Box Collider` をもう 1 つ付けます。

2. その `Box Collider` が、フィールドの台の上を全部覆っているかを確かめます。高さは 0.5 m ほどにします。
   - 覆っている: 手順 3 へ進みます。
   - 覆っていない: **Edit Collider** を押して、大きさを合わせます。合わせたら、手順 3 へ進みます。
3. 一番上のオブジェクトに、`DeliveryZone` が付いているかを確かめます。
   - 付いている: 次の章へ進みます。
   - 付いていない: `DeliveryZone` を付けます。付けたら、次の章へ進みます。

## 6. 体験者が立つ場所を作る
1. 一番上のオブジェクトの子に、`StandArea` があるかを確かめます。
   - ある: 手順 2 へ進みます。
   - ない: 一番上のオブジェクトを右クリックし、**Create Empty** を選びます。名前を `StandArea` にします。このオブジェクトに、`StandArea` コンポーネントを付けます。作ったら、手順 2 へ進みます。
2. `StandArea` が、台の外の、フィールドの手前の床にあるかを確かめます。
   - ある: 手順 3 へ進みます。
   - ない: Scene ビューで `StandArea` を動かします。合わせるのは、横の位置だけです。高さは合わせなくてかまいません。合わせたら、手順 3 へ進みます。
3. `StandArea` の **Field Id** が空かを確かめます。空にしておくと、親の `FieldStages` の名前が使われます。
   - 空: 手順 4 へ進みます。
   - 空でない: 中身を消します。消したら、手順 4 へ進みます。
4. `StandArea` の子に、`Footprint` があるかを確かめます。
   - ある: 手順 5 へ進みます。
   - ない: 次の手順で作ります。作ったら、手順 5 へ進みます。
     - `StandArea` を右クリックし、**3D Object > Cylinder** を選びます。
     - 名前を `Footprint` にします。
     - **Scale** を `(0.5, 0.005, 0.5)` にします。
     - `Capsule Collider` を消します。
5. `StandArea` の **Footprint** の欄に、`Footprint` が入っているかを確かめます。
   - 入っている: 次の章へ進みます。
   - 入っていない: `Footprint` をドラッグして入れます。入れたら、次の章へ進みます。

## 7. 海を光らせる物を作る（海の担当だけ）
物が届いたときの反応（喜ぶ・がっかりする）は、自動で付く `DeliveryFx` が出します。そのため、海以外の担当は、この章を飛ばして次の章へ進みます。

チュートリアル 3 と 4 は、海に `sea.glow` と `sea.glow-off` の合図を出します。海の担当は、この合図で光る物を作ります。

1. 一番上のオブジェクトの子に、`Glow` があるかを確かめます。
   - ある: 手順 2 へ進みます。
   - ない: **Create Empty** で作ります。中に、海が光って見える物を入れます。見た目は自由です。`Glow` は、Inspector の左上のチェックを外して隠しておきます。作ったら、手順 2 へ進みます。
2. 一番上のオブジェクトに、`CueReaction` が付いているかを確かめます。
   - 付いている: 手順 3 へ進みます。
   - 付いていない: `CueReaction` を付けます。付けたら、手順 3 へ進みます。
3. `CueReaction` の **Entries** に、次の 2 行があるかを確かめます。
   - ある: 次の章へ進みます。
   - ない: **+** で行を足し、表のとおりに入れます。足したら、次の章へ進みます。

| Cue | Show | Hide | Seconds |
|---|---|---|---|
| `sea.glow` | `Glow` | | 0 |
| `sea.glow-off` | | `Glow` | 0 |

## 8. 試す
試すときは、テスト用のシーンを複製して使います。テスト用のシーンには、Quest なしで動かせる頭と、食べ物を生む装置が入っています。

1. Prefab を保存して閉じます。
2. Project ウィンドウで `Assets/Scenes/Sandbox/tutorial_test.unity` を選び、Ctrl + D で複製します。名前は `<名前>_field-test` にします。
3. 複製したシーンを開きます。
4. Hierarchy で `TutorialRunner` を選び、Inspector の左上のチェックを外します。チュートリアルを動かさずに、フィールドだけを試すためです。
5. Hierarchy に、自分と同じ名前の仮のフィールドがあるかを確かめます。例えば、海の担当なら `Field_sea` と `Stand_sea` です。
   - ある: 消します。消したら、手順 6 へ進みます。
   - ない: 手順 6 へ進みます。
6. 自分の Prefab を、シーンにドラッグして置きます。
7. Play します。
8. 欲しい物が出るかを確かめます。Inspector の `FieldStages` を右クリックして、**Open Next Want** を押します。Console に、`<名前> wants` で始まる行が出ましたか？
   - 出た: 手順 9 へ進みます。
   - 出ない: 「2. フィールドの名前を付ける」と「3. 欲しい物を並べる」の設定を確かめます。直したら、手順 7 からやり直します。
9. 届いたときの見た目を確かめます。同じ右クリックのメニューで、**Deliver Wanted Food** を押します。欲しい物が届いたときに現れる物が表示され、村人の頭の上に喜びの粒が出ましたか？
   - 現れた: 手順 10 へ進みます。
   - 現れない: 「3. 欲しい物を並べる」の手順 2 の d で、子に置いた物を確かめます。直したら、手順 7 からやり直します。
10. 実際に食べ物を飛ばして確かめます。やり方は下の a〜f です。
    - 物が現れた: 手順 11 へ進みます。
    - 現れない: 「4. 食べ物の表を付ける」と「5. 食べ物が届く範囲を作る」の設定を確かめます。直したら、手順 7 からやり直します。

    - a. Play をやり直します。現れた物は、元に戻ります。
    - b. 手順 8 と同じように、**Open Next Want** を押します。Console に出た食べ物が、いま欲しがっている物です。
    - c. 自分の `StandArea` を右クリックし、**Stand Here** を押します。
    - d. 食べ物を落としたい方へ、顔を向けます。顔の向きは、マウスの右ボタンを押しながら動かすと変わります。W・A・S・D で歩けます。
    - e. Space を押して噛みます。欲しい物の食感が出たら、Enter で決定します。どの食感でどの食べ物が生まれるかは、「4. 食べ物の表を付ける」で作った表のとおりです。
    - f. 食べ物が台の上に落ちたとき、届いたときに現れる物が表示されたかを見ます。
11. 作業ブランチをコミットして、PR を作ります。PR の本文には、何を足したかと、関係する Issue の番号を書きます。複製したテスト用のシーンは、コミットしなくてかまいません。

## 9. HMD で見て、配置と大きさを直す
この章は、1〜8 章を進めている間に、必要になったら行います。全部が済んでから、まとめて行わなくてかまいません。

1. Quest をかぶって、自分のフィールドを見ます。見方は `docs/vr-setup.md` にあります。
2. 物の大きさに違和感がないかを確かめます。
   - ない: 手順 3 へ進みます。
   - ある: Prefab を開いて、大きさを直します。直したら、手順 1 からやり直します。
3. 隣のフィールドとの境目がつながって見えるかを確かめます。村は、北が山、東が海に接します。
   - 見える: 手順 4 へ進みます。
   - 見えない: 隣のフィールドの担当と相談して、境目を合わせます。合わせたら、手順 1 からやり直します。
4. 立つ場所（`StandArea`）が、体験者が自然に立つ位置にあるかを確かめます。
   - ある: この章は終わりです。
   - ない: `StandArea` を動かします。動かしたら、手順 1 からやり直します。
5. 直した所をコミットします。
