# 海の作り込み

海のフィールド（`Sea.prefab`）に、村と同じ仕組みを足す人のための資料です。部品の使い方は [Assets/Scripts/Village/README.md](../Assets/Scripts/Village/README.md) にあります。ここには、配置・素材・見た目・寸法・ステップの決め方を書きます。

いまの `Sea.prefab` には、見た目（船・地形）だけが入っています。ゲームの仕組みはまだありません。この資料の主な目的は、村と同じフィールドの仕組みを足して、本編やチュートリアルにつなぐことです。見た目は、仕組みに合わせて足したり直したりします。

この資料は、村の [docs/village.md](village.md) を手本にしました。節の構成は村と同じです。中身を海に置き換えています。確定していない数字や対応には〔仮〕を付けます。印のないものは、確定か、コードにある事実です。

海のフィールドには、VR のカメラ・餌やりの仕組み・巫女・チュートリアルを入れません。それらは、全部を 1 つにまとめる共有シーンと、土台のコード側のものです。海の Prefab には、フィールドの仕組みと見た目だけを入れます。

## 言葉

この資料に出てくる言葉のうち、初めての人が迷いやすいものを説明します。

- フィールド: ミニチュアの村の中の 1 エリアです。山・海・草原・村があります。体験者は、立つ場所でフィールドを選びます（[docs/fields.md](fields.md)）。
- ミニチュア: 村と全フィールドを乗せた、縮小模型です。その土台を、シーンでは `MinitureBase` と呼びます。
- 食感: 体験者が口から食べ物を生み出すときの、手ざわりの種類です。展示で使うデバイスが出します。
- Quest: 展示で使う VR のヘッドセットです。
- 合図: チュートリアルが「ここを光らせる」などと出す指示です。フィールドが受けて、見せ方を決めます。コードでは `Cues` と呼びます。

## フィールドの仕組み（村と共通）

海の Prefab の根に、村と同じ部品を付けます。これで、シーンに置くだけでゲームの仕組みにつながります。

- `FieldStages`: フィールドの基幹です。Field Id を `sea` にします。Field Id は、このフィールドを見分ける名前です。本編とチュートリアルが、この名前でフィールドを指します。
- `SurfaceAnchor`: 土台の上面に Prefab を乗せます。土台は縦に潰れた形です。その倍率を打ち消し、Prefab の中は 1 = 1 m に保ちます。
- `FoodTable`: 食感と食べ物の対応表です。Field Id を `sea` にします。
- `DeliveryZone`: 食べ物が落ちる判定です。Collider を Is Trigger にします。
- `StepDoneFx`: ステップが済んだときの音と粒です。

根の下に `Steps` を置きます。その下に `FieldStep` を並べます。並び順が、戻る段階の順番です。各部品の設定項目は、[Assets/Scripts/Village/README.md](../Assets/Scripts/Village/README.md) にあります。この資料では繰り返しません。

## シーンと寸法

`Assets/Scenes/Main.unity` の `MinitureBase > Content > Sea` は、立方体の地面です。これが海の土台です。

- `Sea.prefab` は、この地面の子に置きます。`SurfaceAnchor` が上面に乗せ、ゆがみを打ち消します。
- 位置と大きさは、ミニチュアそのものの寸法で決めます。単位はメートルです。
- 海は、村の東側に接します。村側の資料（[docs/village.md](village.md)）に、東が海と書いてあるためです。
- 土台のスケールと、海の 1 辺の長さは〔仮〕です。Unity で土台のスケールを読み、その値で決めます。

## 配置の考え方（海らしく見せるため）〔仮〕

海らしく見せる置き方を書きます。中身は、企画と海の担当が決める項目です。いまは仮です。

1. 船着き場を 1 つ、目が最初に行く所に置きます。
2. 漁の小屋や桟橋を、岸ぞいに置きます。
3. 岩や浮きを、詰め込みすぎずに散らします。
4. 漁をする人は、何かをしている場所に置きます。網を引く、舟に乗る、などです。

村と同じく、置き物を一直線にそろえません。作り物らしさが出るためです。向きも、していることの方に向けます。

## 置き物と素材〔仮〕

置き物と素材を、出るステップと一緒に表にします。海の産物は魚介類です（[docs/fields.md](fields.md)）。素材は、まだ決まっていない所が多いです。

いますでに `Sea.prefab` に入っているのは、船（`Objects` の下）と地形（`Terrain_sea`）です。これらは、ずっとある見た目として残します。下の表は、これから足すものを示します。

| 置き物 | 素材 | 出るステップ |
|---|---|---|
| 〔魚・エビ・貝などの魚介〕 | 〔未定〕 | 1〜（ステップごとに増える） |
| 〔漁をする人〕 | 〔未定。村人の素材を使うかは未定〕 | 常に |
| 〔魚がいない様子（空の網など）〕 | 〔未定〕 | はじめ（飢饉）に出て、済むと消える |

## ステップ〔仮〕

ステップと、見た目と、元気になる人を表にします。村と同じ形です。

海の産物は魚介類です。困っている人は、漁をする人です（[docs/fields.md](fields.md)。漁をする人は〔仮〕）。各食感がどの魚介になるかは、まだ決まっていません。食感の種類は、別の作業（Issue #52）で決まります。そのため、欲しい物の ID は〔仮〕です。

| ステップ（`Steps` の下の並び） | 見た目 | 元気になる人 |
|---|---|---|
| はじめ（飢饉） | 魚がいません。空の網や、干上がった様子です | — |
| 1 〔魚介〕（欲しい物 〔仮〕） | 魚介が 1 種、泳ぎ始めます | 〔漁をする人 1 人〕 |
| 2 〔魚介〕（〔仮〕） | 魚介がもう 1 種、増えます | 〔漁をする人 1 人〕 |
| 3 以降 | 同じ形で増やします | 〔漁をする人 1 人〕 |

1 ステップごとに戻るものは、魚介 1 種と、困っている人 1 人を目安にします〔仮〕。何がいつ戻るかは、`Sea.prefab` の `Steps` の下の並びと、各 `FieldStep` で決めます。

## 困っている人のアニメーション〔仮〕

漁をする人の、困る動きと元気になる動きを決めます。村人の仕組みにならいます。

村人は `VillagerMood` という部品で、困る・うなだれる・喜ぶを切り替えます。動きは `Villager.controller`（Animator の設定）で持ちます（[docs/village.md](village.md)）。海でも同じ部品を使えます。使う素材や動きは〔仮〕です。漁をする人の見た目を、村人の素材から作るかどうかも、まだ決めていません。

## Prefab に仕組みを足す

`Sea.prefab` を手で組みます。海には、村のような生成メニューがないためです（`MouthOfGod` のメニューに Sea はありません）。船と地形は、すでに入っているので、そのまま残します。

1. 根に `SurfaceAnchor` と `FieldStages`（Field Id = `sea`）を付けます。
2. 根に `FoodTable`（Field Id = `sea`）・`DeliveryZone`（Is Trigger）・`StepDoneFx` を付けます。
3. 空の `Steps` を作ります。
4. `Steps` の下に `FieldStep` を持つノードを並べます。欲しい物・困る人・消す物を設定します。項目名と設定の仕方は、[Assets/Scripts/Village/README.md](../Assets/Scripts/Village/README.md) にあります。
5. 各ステップの子に、出る物（魚介など）の見た目を置きます。

## 演出（出方・音）

出方と音は、村と同じ部品で動きます。海で新しく作る必要はありません。

- 出方: ステップの子の物は、出るとき小さい所から「ぽんっ」と大きくなります（`PopInEffect`）。`Steps` の下に物を置くだけで効きます。ステップごとにやめるには、`FieldStep` の `Pop In` を外します。
- 喜びの粒と音: `StepDoneFx`（海の根に付けます）が、ステップが済むと、助かった人の頭の上に粒を出し、短い音を鳴らします。粒と音の素材は、村の `Fx_Joy`（星の粒）と Kenney の音（CC0 の素材）を使えます（[docs/village.md](village.md)）。
- Quest 向け: 粒の数は 20 までにします。衝突・軌跡・ライトは使いません。Quest の描画の負荷を抑えるためです。

## つながり方（置くだけでつながる）

海のフィールドは、シーンに置くだけで、本編・チュートリアル・吹き出しにつながります。登録は、部品が自分で行います。

- `FieldStages` が有効になると、土台のコードの掲示板（`Fields`）に自分を登録します（[Assets/Scripts/Core/Fields.cs](../Assets/Scripts/Core/Fields.cs)）。
- `FoodTable` が有効になると、海専用の対応表として登録します。
- 合図に反応したいときは、海のフィールド側で受けます。合図の名前は、フィールド名から始めます（例: `sea.glow`。[Assets/Scripts/Core/Cues.cs](../Assets/Scripts/Core/Cues.cs)、決まりは [docs/requests.md](requests.md)）。

## 確かめ方

サンドボックスで動きを見ます。

- `FieldStages` の右クリックメニューで、欲しい物を出します（Open Next Want）。吹き出しに欲しい物が出れば、正しいです。
- 同じメニューで、欲しい物を届けます（Deliver Wanted Food）。魚介が増え、助かった人が喜べば、正しいです。
- Play を始めたとき、「Field Id が空」などの警告が出なければ、登録ができています。

## 仮に決めたこと

次の項目は、まだ決まっていません。企画と海の担当が決めます。決まったら、この資料と Prefab を直します。

- 土台のスケールと、海の 1 辺の長さ。
- ステップの数と、各ステップの欲しい魚介。
- 各食感と魚介の対応（`FoodTable` の行）。食感の種類は、Issue #52 で決まります。
- 困っている人の見た目と人数。
- `DeliveryZone` の判定の位置と大きさ。
- はじめ（飢饉）の見た目と、届いた後の見た目。
