# フィールドの定義

本編のフィールドは **山・海・草原・村** の 4 つ（2026-10-13 の MTG で決定。雪原は山エリアに含める。[決めたことの記録](decisions.md)）。ここは、各 Issue（#79 と、その子の #188〜#191）の言葉をそろえるための定義。

- 〔 〕は未決・仮のもの。MTG で決まったら外す。
- #54「対応表」の、生まれる物 → 届け先（フィールド）の表は、下の「フィールドごとの定義」の産物の列。
- 元になったもの: #54 の 10/13 の方針（産物の分け方）、[シナリオブック](scenario-book.md)の「飢饉」、README「3. 体験フロー」。

## 言葉の定義

| 言葉 | 意味 |
|---|---|
| フィールド | ミニチュアの村の中の 1 エリア。山・海・草原・村。体験者は、立つ場所（ミニチュアの周りの位置）でフィールドを選ぶ |
| 産物 | そのフィールドで生まれる・育つもの。体験者が口から生み出して届ける物は、届け先のフィールドの産物になる |
| 足りない状態 | 飢饉で、そのフィールドの産物がなくなっている状態。本編の始まりは、全フィールドがこの状態 |
| 届いた後の状態 | 産物が届き、そのフィールドに現れて増えていく状態。届けた物は村に残る |
| 困っている人 | 産物を欲しがる人。頭の上の吹き出しで欲しい物を見せる。村は村人。ほかは、村から出張してきた人や、漁・狩りをする人など、そのフィールドに合う人にする |

同じ意味で別の言い方をしない（「困りごと」「村人の要求」「欲しい物」は、**欲しい物** にそろえる。吹き出しに出るもの、という意味で使う）。

## フィールドごとの定義

| フィールド | 産物（#54 の方針） | 足りない状態 〔仮〕 | 届いた後の状態 〔仮〕 | 困っている人 〔仮〕 |
|---|---|---|---|---|
| 村 | 穀物・畑のイメージの野菜 | 畑が枯れて何もない | 作物が実る | 村人 |
| 草原 | 肉（小さい順に鶏・豚・牛・象） | 動物がいない | 動物が増える。大きい動物ほど段階が上 | 〔牧畜の人〕 |
| 海 | 魚介類 | 魚がいない | 魚介が泳ぐ | 〔漁をする人〕 |
| 山 | キノコ類・果実類（木を生やす）。雪エリアを含む | 木も実もない | 木が生えて実る | 〔狩猟の人など〕 |

決まっていないこと:
- 各食感がどの物に対応するか。食感の種類が決まる #52 のあとで、この表の隣に足す（#54 から移した）。
- 山に含めた雪エリアで、何を出すか（ペンギン・オオカミ・鹿などが話に出たが未決）。
- 山の「木を生やす」は、物として出すので、「地形を動的に変える演出はしない」とは別。木が生えるのは地形の変形ではなく、物の追加として作る。

## 作るときの目安

各フィールドで、次の 2 つの見た目を用意する。

1. **足りない状態**（始まったときの見た目。産物がない）
2. **届いた後の状態**（産物が増えた見た目）

配置は、重要な物を真ん中に寄せる（貼り合わせで端が切られる前提。#188〜#191）。
