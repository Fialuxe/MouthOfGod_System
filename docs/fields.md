# フィールドの定義

本編のフィールドは **山・海・草原・村** の 4 つです。2026-10-13 の MTG で決めました（[決めたことの記録](decisions.md)）。雪原は山エリアに含めます。この文書は、各 Issue（#79 と、その子の #188〜#191）の言葉をそろえるための定義です。

- 〔 〕は、未決・仮のものを示します。MTG で決まったら外します。
- #54「対応表」には、生まれる物 → 届け先（フィールド）の表があります。この表の中身は、下の「フィールドごとの定義」の産物の列と同じです。
- この定義は、次の 3 つを元にしました。
  - #54 の 10/13 の方針（産物の分け方）
  - [シナリオブック](scenario-book.md)の「飢饉」
  - README「3. 体験フロー」

## 言葉の定義

| 言葉 | 意味 |
|---|---|
| フィールド | ミニチュアの村の中の 1 エリアを指します。山・海・草原・村があります。体験者は、立つ場所（ミニチュアの周りの位置）でフィールドを選びます |
| 産物 | そのフィールドで生まれる物・育つ物を指します。体験者が口から生み出して届けた物は、届け先のフィールドの産物になります |
| 足りない状態 | 飢饉で、そのフィールドの産物がなくなっている状態を指します。本編の始まりでは、全フィールドがこの状態にあります |
| 届いた後の状態 | 産物が届き、そのフィールドに現れて増えていく状態を指します。届けた物は村に残ります |
| 困っている人 | 産物を欲しがる人を指します。頭の上の吹き出しで、欲しい物を見せます。村では村人がこの役になります。ほかのフィールドでは、そのフィールドに合う人にします。たとえば、村から出張してきた人や、漁・狩りをする人です |

同じ意味のものを、別の言い方で呼びません。「困りごと」「村人の要求」「欲しい物」は、**欲しい物** にそろえます。この言葉は、吹き出しに出るものという意味で使います。

## フィールドごとの定義

| フィールド | 産物（#54 の方針） | 足りない状態 〔仮〕 | 届いた後の状態 〔仮〕 | 困っている人 〔仮〕 |
|---|---|---|---|---|
| 村 | 穀物・畑のイメージの野菜 | 畑が枯れて何もない | 作物が実る | 村人 |
| 草原 | 肉（小さい順に鶏・豚・牛・象） | 動物がいない | 動物が増える。大きい動物ほど段階が上になる | 〔牧畜の人〕 |
| 海 | 魚介類 | 魚がいない | 魚介が泳ぐ | 〔漁をする人〕 |
| 山 | キノコ類・果実類（木を生やす）。雪エリアも山に含む | 木も実もない | 木が生えて実る | 〔狩猟の人など〕 |

決まっていないこと:
- 各食感がどの物に対応するかは、まだ決まっていません。食感の種類は #52 で決まります。そのあとで、この表の隣に足します（#54 から移しました）。
- 山に含めた雪エリアで何を出すかは、まだ決まっていません。ペンギン・オオカミ・鹿などが話に出ました。
- 山の「木を生やす」は、物として出します。そのため、「地形を動的に変える演出はしない」という方針とは別の話です。木が生えるのは、地形の変形ではなく、物の追加として作ります。

## 作るときの目安

各フィールドで、次の 2 つの見た目を用意します。

1. **足りない状態**（始まったときの見た目。産物がない）
2. **届いた後の状態**（産物が増えた見た目）

見た目は、貼り合わせで端が切られる前提で作ります（#188〜#191）。そのため、重要な物は真ん中に寄せて配置します。
