# 断り書き・ラベル・マイルストーン・人の名前

## 断り書き

本文の先頭に「🤖 この Issue は Claude（AI）が下書きしました」のような断り書きを付けません。ロボットの絵文字も使いません。Claude が書いたことは、ラベル `claude-proposal` で示します。`clarify-reply` スキルは、このラベルで Claude の下書きだと分かります。

## ラベル

Claude が作る Issue には、必ず `claude-proposal` を付けます。ほかのラベルは、リポジトリにすでにあるものだけを使います（`gh label list`）。新しいラベルは作りません。

## マイルストーン

マイルストーンは、本文に書かずに、Issue の設定で付けます（`--milestone`）。今あるマイルストーンは `gh api repos/{owner}/{repo}/milestones` で確かめます。

## つながり

先に終わっている必要がある Issue は、本文に書かずに、GitHub の Blocked by で付けます。関わる Issue を示すだけなら、本文の最後に `#N` を 1 行で書きます。2 つ以上あるときは、1 行に 1 つずつ並べます。

## 人の名前

`@` を付けて人の名前を書きません。GitHub が、その人に通知を送るからです。人に頼まれたときだけ付けます。
