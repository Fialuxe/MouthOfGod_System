# メモ

作り方がいくつか考えられる所は、本文の最後に「メモ:」で始まる段落として書きます。いちばん簡単な実装と、使う人にやさしい形と、楽しい形は、違うことが多いからです。

メモは、次の順に書きます。

1. いちばん簡単な作り方
2. ほかの作り方（分かりやすさや楽しさを優先した形）
3. チームが話し始めるきっかけになる、軽い問いかけ

## 良い例

> メモ: いちばん簡単なのは、届けた数を英語の文で正面に出す形です。ただ、体験者にとって分かりやすい画面や、楽しい画面は別の形かもしれません。例えば、助けた村人が手を振る、フィールドごとに何を届けたかを並べる、などです。頼まれていない物やよその物を届けたときは、点に入れたほうが面白いでしょうか？

## 悪い例

> 点の付け方は、まだ決まっていません。

言い切ると、決める作業を人に押しつける文に見えます。問いかけにすれば、話し始めるきっかけになります。

> 決めること: 誰がエンディングの中身を決めるか。

「決めること」の節は作りません。人に決めてほしいことがあるときは、`ask-decision` スキルで別にコメントします。
