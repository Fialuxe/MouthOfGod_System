# 題

題は、やる作業を動詞で終える 1 文にします。Bevy の「Add hot keys to navigate the inspector hierarchy quickly」「Remove full_ui testbed」と同じ形です。

## 良い例

- エンディングを作る
- 撮影に使ったローカルのブランチを、リモートに上げる
- 時間切れのあとに、届けた数を出す画面を足す
- 声を入れたときの、セリフとセリフの間隔を試す

## 悪い例

- エンディングがない（状態の題です。何をするかが分かりません）
- 動画の撮影に使ったブランチが、現地の PC にしかない（状態の題です）
- 終了画面: 時間切れのあと、届けた数を出す（「場所: 〜」の形です）
- 【小ゴール】#141 のために、〜できるようにする（飾りの括弧と、別の Issue への寄りかかりがあります）
- feat: add ending（コミットの接頭辞です）

## 目安

- 50 文字以内にします。
- 題に Issue の番号を入れません。
- 同じリポジトリの、ほかの Issue の題とそろえます。
