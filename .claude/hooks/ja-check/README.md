# 日本語チェック（ja-check）

Claude が書く日本語を、読みやすくするための仕組みです。議事録・Issue・PR・コメント・ドキュメント・チャットの返答が対象です。

このリポジトリで Claude Code が動くと、どこでも働きます。自分の PC でも、クラウドのルーティン（議事録・議題・dev-loop・Issue 整理・コンフリクトの調査）でも同じです。

## 何をするか

1. 会話の始めに、書き方のルール（`rules.md`）を Claude に読ませます。
2. GitHub に投稿する直前に、別の小さなモデル（Haiku）が本文を読みます。読みにくければ投稿を止め、直す所を Claude に返します。
3. Claude が返答を終えるときにも、Haiku が読みます。ファイルに書いた日本語と、チャットの返答が対象です。読みにくければ、Claude が書き直します。

書いた本人のモデルは、自分の文の不自然さに気づきにくいです。そのため、別のモデルに読ませます。

## 決まり

- 直すのは言い方だけです。事実・決定・数字・名前・やることは消しません（議事録で特に大事です）。
- 人のコメントに書き足すときは、足した行だけを読みます。人が書いた文は直しません。
- 判定できないとき（claude が見つからない、時間切れ）は、止めずに通します。
- 止めるのは、一度読んでも意味が取れない文だけです。言い回しの好みや、手順で押すボタン・メニューの名前は、問題にしません。
- 一時フォルダの下書きは、返答の終わりには読みません。投稿するときに読みます。
- 止める回数には上限があります。投稿の前は 2 回、返答の終わりは 2 回です。

## 直したいとき

- ルールを足す・変える: `rules.md` を直します。次の会話から効きます。
- 判定の基準を変える: `ja_check.py` の `PRINCIPLE` を直します。
- 止めたい: `.claude/settings.json` の hooks を消すか、Claude Code の `/hooks` から外します。
