# Fork

体験者が持つフォークで、雲を刺したか、先を口に含んだかを判定します。チュートリアル 1 の「雲を刺す → 口に含む」（シナリオブック S3）を進めるために使います。

状態: 案（#51 の途中）。半径などの数字は、すべて仮の値です。

## 部品

| 部品 | 付ける所 | 役割 |
|---|---|---|
| `ForkTip` | フォークの先の位置に置いた、空のオブジェクト | 雲に触れたら「刺した」、口に近づいたら「口に入った」とします。有効になると、自分で `Forks` に登録します。先の当たり判定（小さな球のトリガー）と、動かない Rigidbody は、起動時に自分で付けます |
| `Cloud` | 刺せる雲の見た目（Collider を付けます） | 刺されると隠れます。`Respawn Seconds` たつと戻ります |
| `CloudRing` | シーンのどこか 1 か所 | 体験者の前に、雲を半円状に浮かべます。体験者が歩くと、ついて来ます |

### 判定の決まり

- **刺す:** 先の当たり判定が、`Cloud` の Collider に入ったときです。かけらが付いている間は、ほかの雲に触れても刺しません。
- **口に含む:** 先と口の距離で決めます。`Mouth Enter Radius`（6 cm）以内で入ります。`Mouth Exit Radius`（9 cm）より離れると出ます。半径を 2 つに分けたのは、境目で入る・出るをくり返さないためです。
- **口の位置:** `Mouth` に入れた Transform です。`FoodSpawner` の Spawn Point と同じ `MouthAnchor` を入れます。空なら、Main Camera から `Mouth Offset` だけずらした所を使います。
- **かけらがなくなる:** デバイスで決定したときです。食べ物が生まれるタイミングと同じにしました。先が口の中にあるかは見ません。

## ほかの機能とのつなぎ方

- 参照するのは Core だけです。ほかの機能は、Core の `Forks` から `IFork` を受け取ります。
- フォークの位置は、手（ハンドトラッキング）と AprilTag から推定します。手の位置からフォークの位置を逆算する部品は、まだありません。この部品は人が作ります。
- `ForkTip` は、位置の取り方を知りません。そのため、推定の部品ができても、`ForkTip` を直す必要はありません。
- 雲を光らせる・近くへ寄せるなどの見せ方は、まだありません。合図（`Cues`）を受ける側が足します。

### チュートリアルから待つ

人形劇スクリプト（`TutorialScript`）では、`WaitForPierce` と `WaitForMouth` で待ちます。

```csharp
ForkWait pierce = WaitForPierce(timeoutSeconds: 10f);
yield return pierce;
if (pierce.TimedOut)
{
    // 10 秒たっても刺せないときは、雲を寄せる合図を出す（S3）。合図の名前はまだない
}

yield return WaitForMouth();
```

`WaitForMouth` は、かけらが付いた先を口に含んだときに終わります。かけらなしで口に入れても、数えません。チュートリアル 1 の人形劇スクリプトは、まだありません（#51）。

## 使い方

1. フォークの先の位置に、空のオブジェクトを作ります。名前は `ForkTip` にし、`ForkTip` を付けます。
2. このオブジェクトは、フォークの模型やその当たり判定とは別にします。`ForkTip` が同じオブジェクトの `SphereCollider` を書き換えるためです。自分用の小さなトリガーにします。フォークの位置を推定する部品は、このオブジェクトか、その親を動かします。
3. `ForkTip` の `Mouth` に、Main Camera の子の `MouthAnchor` を入れます。
4. 刺した雲のかけらの見た目があれば、`ForkTip` の子に置きます。`Loaded Piece` に入れると、刺している間だけ表示されます。
5. メニュー **MouthOfGod > Fork > Generate Cloud Prefab** で、雲の Prefab を作ります。白い球を重ねた、仮の見た目です。`Assets/Resources/Prefabs/Fork/Cloud.prefab` にできます。
6. シーンに空のオブジェクトを作り、`CloudRing` を付けます。Play すると、体験者の前に雲が 5 つ浮かびます。

### 雲の置き方（仮）

雲をどこにいくつ浮かべるかは、まだ決まっていません。シナリオブックの未決事項にあります。そのため、`CloudRing` は次の仮の形にしました。どの値も Inspector で変えられます。

- 頭から 45 cm 前、30 cm 下に、5 つ並べます。正面を中心に、120 度の幅に並べます。
- 並べる向きは、Play を始めたときの頭の向きです。首を振っても、雲は動きません。
- 体験者が歩くと、雲はゆっくりついて来ます。シナリオブックの「雲は体験者の周りに、いつも浮かんでいます」に合わせました。
- 雲は、上下に 2 cm ゆれます。

素材の雲ができたら、`Cloud.prefab` の見た目だけを差し替えます。`Cloud` と当たり判定は残します。

### Quest なしで試す

Play 中に、キーで代わりの操作ができます。展示では使いません。

| キー | 操作 |
|---|---|
| P | 雲を刺す |
| M（押している間） | 先を口に入れる |

噛む（Space）と決定（Enter）は、`MockDevice` のキーです。
